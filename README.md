# Sprint_6

Финальный проект 6 спринта: автотесты для учебного сервиса «Яндекс Самокат».

## Что проверяется

1. Выпадающий список в разделе «Вопросы о важном»:
   - проверяется, что при клике на каждый вопрос открывается соответствующий ответ.

2. Заказ самоката:
   - проверяется позитивный сценарий заказа;
   - используются две точки входа: верхняя и нижняя кнопка «Заказать»;
   - используются два набора тестовых данных.

3. Логотипы:
   - клик по логотипу «Самокат» ведёт на главную страницу сервиса;
   - клик по логотипу Яндекса открывает Дзен в новом окне.

## Структура проекта

- `locators/` — локаторы страниц
- `pages/` — Page Object классы
- `tests/` — автотесты
- `conftest.py` — фикстура для запуска и закрытия браузера
- `requirements.txt` — зависимости проекта
- `allure_results/` — результаты Allure-отчёта

## Запуск тестов

```bash
python -m pytest
```

## Запуск тестов с Allure

```bash
python -m pytest --alluredir=allure_results
```

## Открыть Allure-отчёт

```bash
allure serve allure_results
```
